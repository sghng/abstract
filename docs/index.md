# abstract manual

Two bodies of documentation live here. The site is local-only
(`bun run docs:dev`, never deployed).

## [Repertoire manual](/repertoire/)

The convention corpus: what it is, how each layer works, and the recipes for the
next collection round. Start at the [overview + spec](/repertoire/); round work
goes through [fetch](/repertoire/fetch) and [parse](/repertoire/parse); the
[parse report](/repertoire/parse-report) is the failure/quality ledger;
[history](/repertoire/history) records the build arc and the superseded
proposals.

## Harness + prompts

How the lab runs: [the lab](/lab) condenses the operation; the
[multi-agent pattern](/multi-agent) and the
[implementation plan](/harness) describe the retired pi-era harness, kept
for history. Doctrine references: [prompt hierarchy](/prompt-hierarchy),
[prompt doctrine](/prompts), [models](/models), [writing](/writing),
[typ2docx](/typ2docx), and the [ledger](/ledger). The [desk](/desk) is
the user's persistent review queue, and [remote access](/remote-access)
covers the two doors from outside the machine: attach for the owner, the
A2A gateway for the owner's assistant agent.

## Explorations

Dated design explorations, kept as history: [prompt prompting
(2026-10-11)](/prompt-prompting-2026-10-11) surveys Anthropic, OpenAI, and
community skill publishers and records the judgments for the planned
restructure of the harness into a skills plus config repo.

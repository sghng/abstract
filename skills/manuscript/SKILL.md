# Manuscript

<!-- TODO: advanced venue/editor targeting strategies -->

This skill module explains how to prepare a manuscript for publication in
educational assessment/psychometrics field. It covers both paper authoring and
reviewing.

The following skill modules are included:

- `review.md`: workflow of reviewing a manuscript.
- `docx.md`: introduces tooling related to handling Microsoft Word format.
- `nlpatch.md`: introduces the NLPatch (Natural Language Patch) format which is
  a deliverable during paper review.

The authoring workflow itself graduated to the writer's prompt
(`movement/authoring.md` and `movement/prose.md`); this skill now holds review
and format tooling.

## Conventions

- Draft related files should be placed inside the `draft/` directory.
- A `story.md` file is used to keep track of the story telling strategy. All
  drafting and reviewing should closely follow the story and do not go astray.
- For writing conventions (formatting, language, reporting rules), see the
  tuning and prose movements; these are the single source of truth.

# Preparing a Presentation

A presentation is a paper distilled to its emotional arc. Every slide should
make the audience lean forward, not lean back. This skill comprises the
following components:

- `preparation.md`: curating content and designing the storytelling strategy
  from `notes/story.md`.
- `slides.md`: how to create slides.
- `review-and-iteration.md`: compiling, delegating the visual review, and
  iterating.
- `references/presentation.md`: the standing doctrine behind the deck (voice,
  structure, captions, figures, audience discipline, fit).
- `assets/deck.typ`: the house starter deck (touying simple theme); every new
  deck starts as a copy of it.

Slides are Typst, so the typst skill rides along for syntax and package
doctrine.

# Preparing a Presentation

This skill helps you prepare for an academic presentation. It involves how to
curate content, design story telling strategies, and create visually appealing
slides.

This skill comprises the following components:

- `preparation.md`: How to prepare the content, how to design story telling
  strategy, and the `story.md` file for keeping track of the story.
- `slides.md`: How to create slides.
- `review-and-iteration.md`: The review and iteration process to ensure the
  presentation meets our standard.
